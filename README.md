一个面向 Xiaomi Vela 手表的可自定义陪伴应用。当前以 REDMI Watch 6 标准版为主要目标，其他设备尚未逐一验证。

首页把状态与互动合在一个房间场景里：顶部图标与数值，中间的大角色和气泡，底部摸头、喂食、陪玩图标，保留聊天和设置入口。

## 普通用户怎么用

1. 从维护者的发布页获取 RPK，用安卓上的 AstroBox 安装一次。
2. 在手表设置里创建配对，手机扫描二维码。
3. 手机网页修改名字、称呼、形象或背景后保存。手表停留在自定义页时自动检查，也可以手动同步。
4. 后续换角色不需要重新打包，不需要每次连接电脑。需要配套服务和手机代理联网；断网时继续使用已保存的角色和离线养成功能。

这里提供的是本地工程与示例，不是已经上线的公共服务。维护者先部署服务、配置地址并发布固定签名的安装包，普通用户才能直接扫码使用。本版本同步链路已在本机用浏览器和模拟设备 API 验证；手表原生二维码、下载和文件接口仍需真机验收。

## 开发与自部署

需要 Node.js 22+。构建手表程序还需要 npm 和 openssl。

```bash
npm ci
npm test
npm run companion
```

服务默认 `127.0.0.1:8787`，不会自动公开到互联网。局域网测试可自行设置 `HOST=0.0.0.0`，并在手表中填写手机能访问的局域网地址；正式服务使用 HTTPS、固定域名和持久化数据目录。

Docker 运行方式：

```bash
docker build -t watch-pet .
docker run -p 8787:8787 -v watch-pet-data:/data watch-pet
```

为发布包预设服务地址后构建：

```bash
node scripts/set-sync-origin.mjs https://your-companion.example
cd watch
npm ci
npm run release
```

`watch/sign/` 保存项目签名，正式发布的所有更新必须沿用它。签名私钥、模型密钥和用户角色包都不放入公开仓库。下载并安装 RPK 仍需要兼容的第三方安装工具，不是 Android APK，也没有声称能绕过平台限制。

## 自定义能力

- 手机本地处理形象图片和背景；保存时传到自己的配套服务。
- 单张透明 PNG 即可作为静态角色使用；有动作素材时可以导入 8 × 11 图集。
- 支持角色名、对用户的称呼、背景和动作帧。
- 养成存档与角色资源分开；保留上一份形象供恢复。
- 同步只在设置页可见时检查，退出后停止轮询；不会靠常驻后台持续传图。

包格式见 `ROLE_PACK.md`。资源来源见 `ASSETS.md`。代码采用本地拟定的 MIT 许可；维护者应在实际公开发布前确认自己的许可选择。

## 范围与后续验收

当前版没有改聊天界面。名字、称呼自定义先用于小屋与互动；聊天人格配置、AI 服务选择和模型接入仍是独立阶段。单图不会自动变成动画。

本机检查包括 HTTP 配对鉴权、图片校验、并发修改、服务端发布、模拟设备下载、存档提交后回执、失败保留旧配置、恢复旧版存档。浏览器验证过改名、选图和保存。

上线前仍需确认：Watch 6 真机布局、二维码扫码、手机代理联网、原生下载与文件存储、覆盖升级后的存档、断网重试、图片加载失败、熄屏和一天耗电。当前服务适合小规模自部署试用；大规模推广前还需账号/配对撤销、服务配额、数据备份、过期数据清理和运营监控。

## 目录

- `watch/`：手表应用与官方 Vela 构建入口。
- `companion/`：手机自定义网页、配对与素材同步服务。
- `server/`：现有可配置聊天代理，默认不含模型凭据。
- `examples/`：通用示例角色与动作图集。
- `test/`：状态与同步链路检查。

没有替使用者创建代码仓库、上传素材或发布公共服务。
